# 0.5.1 — анимация рук отключается в VR

Запрос (2026-10-07): «сделай чтобы отключались анимации у рук когда VR режим включался».

- hands.cpp: при включённом VR (пешком) руки полностью задаются контроллерами. Фоновый поток пишет в скелет
  плечо -> локоть -> кисть по двухзвенной IK от плеча до цели контроллера (та же цель, что у SET_IK_TARGET).
  Анимация игры на руках (махи при ходьбе, стойки с оружием, idle) перезаписывается каждый кадр.
  Кости: SKEL_*_UpperArm, *_ArmRoll, MH_*_Elbow, SKEL_*_Forearm, *_ForeArmRoll, кисть и пальцы.
  Локоть смотрит вниз-назад-наружу.
- VR выключен, в машине, контроллер потерян -> руки снова отдаются игре (писатель останавливается через 50 мс).
- После смены персонажа кости рук берутся заново.
- GTA5VR.ini: arm_override=1 (0 = как в 0.5.0, только игровой IK).
- Лог: "arms: ... arm bones ... override possible", "arms: animation override applied N times in 5 s".

В игре не проверено. ID костей рук взяты из известной схемы скелета GTA V, в этой сборке не проверены.
