GTA V Hands VR 0.2.7 — VR-мод для GTA V (тестовая сборка, только сюжетный режим)
=================================================================================
Цель мода: камера от первого лица следует за головой, руки персонажа повторяют
движения контроллеров, правый контроллер — прицел, курок — выстрел.

ВНИМАНИЕ: это ранняя тестовая (DEV) версия. Полноценно играть пока нельзя.
Только сюжетный режим. Моды в GTA Online могут привести к бану аккаунта.

ТЕКУЩЕЕ СОСТОЯНИЕ (честно)
--------------------------
Проверено по логам на реальном ПК (Pico + SteamVR, RTX 2060 SUPER):
  [работает] мод загружается через Script Hook V, F8 включает/выключает VR;
  [работает] подключение к SteamVR (мод сам выбирает SteamVR);
  [работает] кадры отправляются в SteamVR (~60 кадров/с, без ошибок);
  [работает] повторное включение VR по F8, авто-выключение при зависании;
  [работает] руки персонажа двигаются за контроллерами (положение).
Известные проблемы:
  [НЕ работает] в шлеме видна среда SteamVR с надписью «загрузка» вместо игры —
                ищем причину (см. «ПРОВЕРКА F10» ниже);
  [НЕ работает] кисти рук смотрят вниз: Script Hook V позволяет задать только
                положение кисти, но не её поворот;
  [не проверено] камера от головы, прицеливание и стрельба контроллером,
                поворот правым стиком, объёмный режим stereo=1;
  [нет] руль двумя руками в машине (в машине — обзор головой + кнопки).

ВСЕ ВОЗМОЖНОСТИ
---------------
VR:
  - VR через OpenXR, по умолчанию SteamVR (Pico Connect / Streaming Assistant -> SteamVR);
    runtime=system в GTA5VR.ini — использовать среду OpenXR, выбранную в Windows.
  - Включение по F8 прямо в игре (SteamVR можно запустить в любой момент до F8).
  - Режим «моно» (одна картинка на оба глаза, по умолчанию) или «стерео»
    (stereo=1, кадры по очереди для каждого глаза, экспериментально).
  - Камера: поворот и наклон головы, небольшое перемещение головы в комнате (до 40 см).
  - F9 — «перед» там, куда вы сейчас смотрите. Правый стик — поворот на 30°.
Руки и оружие:
  - Руки персонажа тянутся к контроллерам (F11 — выключить/включить).
  - Правый курок — выстрел туда, куда направлен правый контроллер.
  - Левый курок — прицеливание.
Управление движением:
  - Левый стик — ходьба (вперёд = куда смотрите), нажатие стика — бег.
  - A — прыжок, B — сесть/выйти из машины, X — перезарядка.
  - В машине: правый курок — газ, левый — тормоз, левый стик — руль.
Безопасность и удобство:
  - Мод выключается сам в GTA Online (работает только в сюжете).
  - VR не включается сам в меню: только по F8.
  - Если кадр завис дольше 3 с — VR выключается, игра продолжает работать.
  - В меню паузы и на загрузках камера возвращается к обычной.
  - Подробный журнал GTA5VR.log (статистика кадров каждые 2–10 с).
Установка:
  - setup.bat: одним запуском находит игру, удаляет старые файлы мода,
    скачивает мод и Script Hook V и всё копирует.

ЧТО НУЖНО
---------
1. GTA V Legacy (файл GTA5.exe). GTA V Enhanced (GTA5_Enhanced.exe) не поддерживается.
2. Script Hook V (автор Alexander Blade) — setup.bat скачает его сам:
   https://www.dev-c.com/gtav/scripthookv/
3. VR-шлем (Pico 4 / Pico Neo и др.) и SteamVR.

УСТАНОВКА — ОДНИМ СКРИПТОМ
--------------------------
1. Закройте GTA V.
2. Скачайте setup.bat: https://github.com/ctenadog/gta5-hands-vr/releases/tag/latest
   (раздел Assets). НЕ берите «Code -> Download ZIP» / «Source code» — там исходники.
3. Запустите setup.bat двойным щелчком (если Windows предупредит —
   «Подробнее» -> «Выполнить в любом случае»).
4. Script Hook V уже стоит? Нажмите Enter, чтобы оставить его.
5. В конце должно быть «ГОТОВО».
Если сайт Script Hook V не даст скачать автоматически — откроется браузер,
нажмите Download, скрипт сам заберёт файл из «Загрузок».

Установка вручную: распакуйте GTA5VR-0.2.0.zip в любую папку (не в папку игры)
и запустите install.bat; ScriptHookV.dll и dinput8.dll (из папки bin архива
Script Hook V) положите рядом с GTA5.exe.

ЗАПУСК
------
1. Подключите шлем к SteamVR (в SteamVR шлем должен гореть зелёным).
2. Запустите GTA V и загрузите СЮЖЕТНЫЙ режим.
3. Посмотрите прямо и нажмите F8. Повторное F8 — выключить VR.

КЛАВИШИ И КНОПКИ
----------------
Клавиатура:
  F8   — включить/выключить VR
  F9   — сбросить направление «вперёд»
  F10  — проверка: залить шлем цветом (левый глаз розовый, правый зелёный)
  F11  — включить/выключить управление руками
Контроллеры:
  Левый стик            — ходьба (в машине — руль)
  Нажатие левого стика  — бег
  Правый стик влево/вправо — поворот на 30°
  Правый курок          — выстрел (в машине — газ)
  Левый курок           — прицеливание (в машине — тормоз)
  A                     — прыжок
  B                     — сесть в машину / выйти
  X                     — перезарядка

НАСТРОЙКИ (GTA5VR.ini в папке игры, создаётся при первом F8)
------------------------------------------------------------
  runtime=steamvr   — использовать SteamVR (по умолчанию); system — среда Windows
  stereo=0          — моно (по умолчанию); 1 — объёмная картинка (экспериментально)
  latency=1         — если картинка «плывёт» при поворотах головы, попробуйте 2 или 0
После изменения нажмите F8 два раза (или перезапустите игру).

ПРОВЕРКА F10 (если в шлеме «загрузка»)
--------------------------------------
Включите VR (F8), подождите 5 с, нажмите F10 один раз:
  - розовый/зелёный экран — кадры доходят, проблема в переносе картинки игры;
  - всё так же «загрузка» — SteamVR не показывает кадры мода.
Сообщите результат и пришлите GTA5VR.log.

ЕСЛИ НЕ РАБОТАЕТ
----------------
Пришлите файл GTA5VR.log из папки игры (первая строка — версия мода).
Частые причины: нет ScriptHookV.dll или dinput8.dll; Script Hook V не подходит
к версии игры; SteamVR не запущен или шлем не подключён к нему в момент F8.

УДАЛЕНИЕ
--------
Удалите из папки игры GTA5VR.asi, openxr_loader.dll, GTA5VR.log, GTA5VR.ini
и папку GTA5VR. Script Hook V (ScriptHookV.dll, dinput8.dll) — по желанию.
