# GTA V Hands VR

VR mod for GTA V Legacy story mode: head-tracked first-person view, your character's arms follow the VR controllers, aim with the gun in your hand. Works with any SteamVR headset (tested on Pico Neo 3 via PICO Connect).

## Установка (RU)

1. Скачайте **setup.bat** со страницы [Releases → latest](https://github.com/ctenadog/gta5-hands-vr/releases/tag/latest) и запустите.
2. Запустите SteamVR, затем GTA V в сюжетном режиме, нажмите **F8**.

F8 включает и выключает VR, F9 делает «смотреть прямо». Подсказки показываются в игре. Подробно: [README_RU.txt](README_RU.txt). Удалить мод: **uninstall.bat**.

Не скачивайте «Code → Download ZIP» и «Source code»: это исходники, а не мод.

## Install (EN)

1. Download **setup.bat** from [Releases → latest](https://github.com/ctenadog/gta5-hands-vr/releases/tag/latest) and run it. It finds the game and installs the mod plus Script Hook V.
2. Start SteamVR, then GTA V story mode, press **F8**.

F8 toggles VR, F9 recenters. Controllers: left stick move (click = sprint), right stick turn, right trigger fire / throttle, left trigger aim / brake, A jump, B enter/exit vehicle, X reload, Y next weapon.

Story mode only; the mod switches itself off in GTA Online. DEV build. If something breaks, send `GTA5VR.log` and `GTA5VR_Host.log` from the game folder.
